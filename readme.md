# Social Media Usage and Academic Performance Dashboard

## Project Overview

This project is an interactive dashboard developed to analyse social media usage patterns among college students and explore their relationship with academic activities.

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dashboard Features

* Interactive dashboard overview
* CSV dataset upload
* Dataset validation
* Social media platform analysis
* Usage purpose analysis
* Academic impact visualization
* Social media usage versus study hours analysis
* Correlation analysis
* Interactive data filters
* Downloadable research dataset
* Downloadable research summary report

## Project Structure

* `app.py` – Main Streamlit dashboard
* `sample_data.csv` – Fictional demonstration dataset
* `read_data.py` – Reads and displays dataset information
* `usage_analysis.py` – Analyses social media usage
* `study_analysis.py` – Analyses study hours
* `platform_analysis.py` – Analyses popular platforms
* `purpose_analysis.py` – Analyses usage purposes
* `academic_impact_analysis.py` – Analyses reported academic impact
* `test_environment.py` – Checks the Python environment

## How to Run

1. Install Python.

2. Install the required libraries:

   `pip install -r requirements.txt`

3. Open the Prototype folder in the terminal.

4. Run:

   `streamlit run app.py`

5. Open the dashboard in your browser.

## Dataset Information

The current dataset contains fictional demonstration records for testing the dashboard. It does not represent actual survey responses or research findings.

Actual anonymized survey data will be used after data collection.

## Research Purpose

The dashboard supports the research project titled:

**An Analytical Study of Social Media Usage Patterns and Their Influence on Academic Performance Among College Students.**

# PROTOTYPE DEVELOPMENT PLAN

## Project Name

Social Media Usage and Academic Performance Analysis Dashboard

## 1. Objective

To develop an interactive website that presents social media usage patterns among college students through charts, statistics and visual reports.

## 2. Technology

* Python – Programming language
* Streamlit – Website development
* Pandas – Data processing
* NumPy – Numerical calculations
* Matplotlib and Seaborn – Data visualization

## 3. Main Dashboard Features

### Overview

Display the total number of survey responses and key statistics.

### Social Media Usage

Show commonly used platforms and daily usage duration.

### Usage Purpose

Visualize educational, entertainment and communication-related usage.

### Academic Activities

Explore the relationship between social media usage and students' self-reported study habits.

### Data Visualization

Display interactive charts and graphs.

## 4. Expected Output

An interactive website that helps users understand social media usage patterns and explore their relationship with academic activities.

## 5. Data Source

The final dashboard will use anonymized survey responses collected for this research. Sample data may be used during development and will be clearly labelled as demonstration data.
